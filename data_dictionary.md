# Data Dictionary

| Field | Meaning |
|---|---|
| Month | Reporting month |
| Channel | Marketing/acquisition channel |
| Marketing_Spend | Spend assigned to channel |
| Leads | Leads generated |
| Customers_Acquired | Customers attributed to channel |
| Average_Order_Value | Average revenue per order |
| Revenue | Attributed revenue |
| Repeat_Customers | Repeat customers |
| Conversion_Rate | Customers divided by leads |
| Cost_Per_Lead | Spend divided by leads |
| CAC | Spend divided by customers |
| ROMI | (Revenue - Spend) divided by spend |
| Repeat_Customer_Rate | Repeat customers divided by customers |
