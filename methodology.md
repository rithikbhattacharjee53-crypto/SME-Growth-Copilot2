# Methodology

1. Define the management decision.
2. Prepare business data.
3. Calculate core KPIs.
4. Compare channels and time periods.
5. Identify trends, inefficiencies and opportunities.
6. Visualize findings.
7. Use AI-assisted interpretation to translate findings into management language.
8. Validate recommendations against source metrics.

## Core formulas

- Conversion Rate = Customers Acquired / Leads
- CPL = Marketing Spend / Leads
- CAC = Marketing Spend / Customers Acquired
- ROMI = (Revenue - Marketing Spend) / Marketing Spend
- Repeat Customer Rate = Repeat Customers / Customers Acquired

The project uses synthetic demonstration data.
